[c/FFE900:This mod improves some aspects of vanilla chests]

____[c/FFE900:Changes]_____________
- "Deposit All", "Loot all", "Sort" have a confirmation button now. (separately toggleable in the config)
- Added a search bar inside chests!
- Right clicking on "Sort Items" in a chest or right clicking "Sort Inventory" will open a menu with more sort options.
- Hovering over a chest shows its contents.
- Hotkeys for Deposit All, Loot All, Quick Stack, Restock, Sort Chest and Sort Inventory.
- Added a Config option to change the functionality of the "Sort Items" button.
- Multiple players can use a chest at the same time now! (might make duplicated when holding right click on items)
- You can now own chests, locks chests for other players so that they can't open or quick stack them.
- You can ping items in chests. The items get highlighted in the chest and displayed on the map, chests containing pinged items get highlighted. Additionally, a chat message gets sent

____[c/FFE900:How to use]_____________
More sort options:
[c/C4C4C4: Simply open a chest and right click on "Sort Items".]
[c/C4C4C4: This will open another menu to the right.]

Default sort option and confirmations:
[c/C4C4C4: Open Mod Config to change the "Sort Items" button.]
[c/C4C4C4: You can disable the confirmation messages there.]

Search bar:
[c/C4C4C4: Use the search bar to search for items.]
[c/C4C4C4: There's also hotkey to focus it. Press Escape to unfocus.]

Chest Ownership:
[c/C4C4C4: Click the lock button under "Rename" to toggle ownership.]

Item Pinging:
[c/C4C4C4: Right-click an item in a chest while holding the Ping Hotkey]
[c/C4C4C4: - default: Left-Alt, might need to be set first]
